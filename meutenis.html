Projeto de desenvolvimento web

Uma loja online feita para quem ama tênis.

O Meutênis é um projeto de e-commerce desenvolvido em grupo, com foco na experiência de compra, organização da loja e comunicação entre clientes e administrador.

👟
MEUTÊNIS ESTILO • CONFORTO • TECNOLOGIA
01 / Sobre o projeto

Uma experiência de loja virtual

O projeto reúne páginas de uma loja de calçados esportivos e recursos de gerenciamento. A interface utiliza uma identidade visual com tons de laranja, pensada para manter a navegação consistente entre as telas.

🛍️

Loja virtual

Estrutura de e-commerce voltada à apresentação e à navegação por produtos de tênis.

🔐

Contas de usuário

Páginas de login e cadastro conectadas ao sistema de autenticação do projeto.

💬

Comunicação

Área de conversa para aproximar clientes e administrador dentro do projeto.

02 / Funcionalidades

Recursos desenvolvidos

As funcionalidades são divididas entre os integrantes do grupo. A página destaca os recursos observados no projeto sem atribuir todo o desenvolvimento a uma única pessoa.

Login e cadastro

Formulários para que os usuários possam acessar o sistema e criar uma conta.

Painel administrativo

Área de administração para acessar recursos de gerenciamento da loja.

Chat cliente–administrador

Mensagens persistidas no banco de dados, visualização das conversas e organização do atendimento.

03 / Galeria

Telas do projeto

Algumas telas do Meutênis e da funcionalidade de conversa. Clique nas imagens para ampliar usando o navegador.

Observação: para a galeria funcionar, mantenha a pasta imagens junto com este arquivo HTML. As capturas são exemplos das telas disponíveis, não uma demonstração ao vivo do sistema (Por que ainda não aprendi a hospedar sites ).
04 / Minha contribuição

Desenvolvimento do chat e do painel

Minha participação no projeto ficou concentrada principalmente no sistema de conversa entre cliente e administrador e na área de atendimento do vendedor.

01

Chat entre cliente e administrador

Desenvolvimento da interface e da comunicação para envio e visualização das mensagens.

02

Persistência das mensagens

Integração com PHP e MySQL para guardar as mensagens no banco de dados.

03

Visualização das conversas

Área administrativa para consultar as conversas e acompanhar as mensagens recebidas.

04

Organização do atendimento

Recursos como contador de mensagens não lidas e marcação de mensagens como lidas.

O carrinho, os pagamentos e outras partes da loja são responsabilidades separadas no trabalho em grupo e não são apresentados aqui como minha contribuição individual.
